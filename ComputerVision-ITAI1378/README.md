# Computer Vision and AI - ITAI 1378

## Course Overview

This course introduced practical computer vision concepts and tools used to analyze, classify, detect, and segment objects in images. Coursework included image processing, classical machine learning, neural networks, convolutional neural networks, object detection, image segmentation, evaluation metrics, and visual language models.

## Skills Developed

- Classical machine learning
- Neural networks
- Convolutional neural networks
- Object detection
- Image segmentation
- YOLO11
- SAM 2
- Model evaluation
- Confidence thresholds
- Precision, recall, IoU, and mAP
- Google Colab
- Jupyter Notebooks
- GitHub documentation

## Featured Projects

### sHū addi Smart Inventory Counter

A YOLO11 proof of concept that processes retail product images, detects supported objects, draws bounding boxes, and generates an inventory count.

[View project repository](https://github.com/ericjonsmithii-arch/SHU-Addi-Smart-Inventory-Counter)

### Object Detection and Image Segmentation Lab

A hands-on lab comparing object detection and image segmentation using YOLO11, YOLO11-seg, and SAM 2.

### Chihuahua or Muffin CNN

A convolutional neural network project that classified images as either Chihuahuas or muffins while demonstrating convolution, pooling, activation, dropout, and classification layers.
